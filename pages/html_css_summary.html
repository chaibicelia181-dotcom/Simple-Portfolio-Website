HTML summary

1. Document Structure

Every HTML page begins with a standard template. <!DOCTYPE html> declaration tells the browser which version of HTML is being used. The <html lang="en"> element wraps the entire document and specifies the language. Inside, the <head> holds metadata, and the <body> contains everything the user sees. <meta charset="UTF-8"> is for character encoding, <meta name="viewport"> for responsive dispay on smaller screens, <link rel="stylesheet"> in order to link to an external css file, <title> for the page title shown in the browser, and <body> where all the content goes.

2. Headings

HTML provides six levels of heading: <h1> through <h6>. <h1> is the most important (there should only be one per page), while <h6> is the least prominent. Headings create visual hierarchy and help screen readers navigate the page.

5. Images

The <img> tag embeds images. It is a self-closing tag (no closing tag needed). Attributes:

  • src: Path to the image file
  • alt: Alternative text for screen readers when image fails to load
  • width / height: Set dimensions
  • border: Adds a border (older HTML attribute; prefer CSS)

6. Hyperlinks

The <a href="..."> anchor tag creates a hyperlink. Its main attributes are:

  • href: The URL destination
  • target="_blank": Opens the link in a new tab
  • rel="noopener noreferrer": Security attribute used with target="_blank"

7. Tables

Tables organise data into rows and columns. Key elements:

  • <table>: The container element
  • <thead>: Table head group
  • <tbody>: Table body (contains data rows)
  • <tr>: Table row
  • <th>: Table header cell
  • <td>: Table data cell
  • cellpadding, cellspacing, border: Table attributes

CSS summary

CSS (Cascading Style Sheets) controls the visual presentation of HTML pages. There are three ways to apply CSS: inline , internal , and external.

1. Selectors

Element Selector

Targets all instances of a tag: p { }, h1 { }, nav { }

Class Selector

Targets elements with a class: .card { }, .btn { }

ID Selector

Targets one unique element: #contact-section { }, #about { }

Pseudo-class / Pseudo-element

:hover, :last-child, :nth-child(), ::before, ::after

2. Text and Font Properties

  • color: Text colour (named, hex, rgb)
  • font-size: Text size (px, rem, em, vw, clamp())
  • font-family: Font type. Portfolio uses Google Fonts: Cormorant Garamond & DM Sans
  • font-weight: Bold/thin: 300, 400, 500, 600, 700
  • font-style: italic or normal
  • text-align: left, center, right, justify
  • text-decoration: underline, line-through, none
  • text-transform: uppercase, lowercase, capitalize
  • letter-spacing: Space between characters
  • line-height Space between lines

4. Backgrounds

  • background-color: Solid background colour
  • background-image : Image as background. Portfolio uses linear-gradient() and radial-gradient()
  • background-size: cover: Scales image to cover the element
  • background-repeat: no-repeat: Prevents tiling
  • background-position: center: Positions the background image

5. Display and Position

  • display: block: Full-width block element
  • display: inline: No line break
  • display: inline-block: Block-like box model
  • display: none: Hides the element
  • position: relative: Positioned relative to its normal position
  • position: absolute: Positioned relative to the nearest positioned ancestor
  • position: fixed: Fixed to the viewport
  • position: sticky: Sticks to the viewport when scrolling (used alot for navigation bars)
  • z-index: Controls the stacking order of elements
  • overflow: hidden / auto: Manages content that exceeds the element size

6. Flexbox

CSS Flexbox is a one-dimensional layout method.

  • display: flex: Enables flex layout
  • flex-direction: row / column: Direction of the main axis
  • justify-content: Alignment on the main axis: space-between, center, flex-start
  • align-items: Alignment on the cross axis: center, flex-start, flex-end
  • flex-wrap: wrap: Allows items to wrap to the next line (used in nav, language strip)
  • flex-grow: Controls how much a flex item grows
  • flex-basis: Default size of a flex item before growth
  • align-self: Overrides align-items for one specific item
  • gap: Spacing between flex items

7. CSS Grid

CSS Grid is a two-dimensional layout system.

  • display: grid : Enables grid layout
  • grid-template-columns : Defines columns
  • grid-template-rows : Defines row heights
  • gap : Space between grid cells
  • grid-column: 1 / -1 : Merging method 1: spans item across all columns
  • grid-template-areas : Merging method 2: named layout regions
  • justify-items : Horizontal alignment of grid items
  • align-items : Vertical alignment of grid items

  • animation: name duration timing fill: Applies a keyframe animation
  • animation-delay: It means the start of the animation
  • transform: translateY() / translateX() / scale() / rotate(): Geometric transformations
