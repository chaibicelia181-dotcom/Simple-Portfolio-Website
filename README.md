# Simple Portfolio Website

A clean and responsive personal portfolio website built using **HTML5**, **CSS3**, and **JavaScript** . This project showcases a modern portfolio layout that can be customized to highlight your personal profile, skills, projects, and contact information.

---

## Features

- Responsive and mobile-friendly design
- Clean and modern user interface
- Easy to customize
- Semantic HTML structure
- Organized CSS styling

---

## Technologies Used

- HTML5
- CSS3
- Javascript


Open `pages/index.html`
